> 目标：用一个固定的 SysY 程序贯穿整次作业，完整观察“源程序 → LLVM IR → 汇编 → 目标文件 → 可执行程序”的处理过程，并分别手写等价 LLVM IR 与 RISC-V 汇编，完成运行验证。最后再做优化对比和 MLIR 进阶探索。

> 本文档是执行方案，不是最终实验报告。原则是：**先把实验全部做通并保留证据，再统一写报告。**

## 一、作业目标与范围

第一次作业分为两部分：

- **基本要求：4 分**
  - 研究一个成熟编译工具链的完整语言处理过程。
  - 理解预处理器、编译器、汇编器、链接器分别做什么。
  - 进一步理解编译器内部的主要阶段。
  - 设计一个覆盖典型 SysY 语言特性的示例程序。
  - 编写与该 SysY 程序语义等价的 LLVM IR。
  - 编写与该 SysY 程序语义等价的 RISC-V 汇编。
  - 将 LLVM IR 与 RISC-V 汇编分别编译、链接、运行，验证结果正确。

- **进阶要求：1 分**
  - 观察 MLIR 多级 IR 的 lowering 思路。
  - 以 AscendNPU IR 的 VecAdd 为主线，理解 Arith / HFusion / HIVM / HACC / LLVM IR 的逐层变化。
  - 若环境搭建困难，可以以官方资料和课程材料中的 lowering 过程分析为主，不强制真实上板。

整次作业只使用 **一个核心示例程序**，不重复做多个相似程序。

## 三、贯穿整个作业的 SysY 程序

固定使用下面的程序：

```c
int calc(int n) {
    int i = 1;
    int sum = 0;

    while (i <= n) {
        if (i % 2 == 0) {
            sum = sum + i * 2;
        } else {
            sum = sum + i;
        }

        i = i + 1;
    }

    return sum;
}

int main() {
    int n;
    n = getint();

    int result;
    result = calc(n);

    putint(result);

    return 0;
}
```

### 1. 覆盖的语言特性

该程序覆盖：

```text
整型变量
赋值
整数常量
加法
乘法
取模
比较
if / else
while
函数定义
函数参数
函数返回值
函数调用
运行时输入输出
```

这已经足以覆盖第一次作业需要观察的核心结构。

### 2. 标准语义

程序执行：

```text
输入 n
  ↓
i 从 1 遍历到 n
  ↓
奇数：sum += i
偶数：sum += 2 * i
  ↓
返回 sum
  ↓
输出结果
```

固定测试集：

| 输入 | 期望输出 |
| ---: | ---: |
| 1 | 1 |
| 2 | 5 |
| 3 | 8 |
| 4 | 16 |
| 5 | 21 |
| 10 | 85 |

后续：

## 5. 重点理解 Lowering

不要把 lowering 理解成：

```text
高层代码直接“变成机器码”
```

而要理解：

```text
一个高层 Op
      ↓
逐渐拆成更低层的 Op
      ↓
每下降一层，引入更多硬件细节
```

例如：

```text
hfusion.vadd
      ↓
load
vadd
store
```

同时开始显式出现：

```text
GM
UB
同步
内存分配
```
